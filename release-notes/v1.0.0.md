## WatchTower v1.0.0

**Chronos is now WatchTower** - the same private, local screen-time intelligence for Windows, rebuilt with a new name, a new look and a lot more polish. Your existing data is kept: an older `%APPDATA%\Chronos` folder is moved to `%APPDATA%\WatchTower` automatically on first start.

### New
- **Five live 3D watchtower logos** - Classic Tower, Seaside Lighthouse, Stone Keep, Pagoda Watch and Sky Observer, each with a rotating model and a sweeping yellow searchlight. Pick one in *Appearance*: previews rotate live, and your choice is applied to the sidebar, the tray, the taskbar, Desktop and Start Menu shortcuts (including pinned tiles) and the launcher file itself.
- **Rounded, frameless window** with five title bar styles (Windows, macOS traffic lights, Minimal, Floating, Classic) and corner rounding from 0 to 24 px.
- **System tray** with a small rounded quick panel: live time, page shortcuts, pause/resume, open, quit.
- **Desktop options**: launch at Windows startup, *launch in the system tray* (off = opens in front of you), minimize/close to tray, confirm before exit. `WatchTower.exe --quit` shuts a running instance down gracefully.
- **Heat Map inside Statistics**, with *Selected hour* and *Selected weekday* detail panels for the Hourly and Weekly views.
- **Live everything**: Statistics, Applications, Sessions, Timeline and the Heat Map refresh every second with sliding HH:MM:SS digits; the application distribution shows live, sliding times.
- **Timeline Inspect button** below the date range opens the selected session in a window.
- **Filters are remembered** across menus and restarts (Applications, Sessions, Statistics range and tab, Heat Map view).
- **Notifications** in the bottom-right corner show exactly where an export was saved and what an import added.
- **Personal touches**: type your name beside the greeting, level and XP card on the Overview, daily goal, 57 achievements (44 new), 12 themes, 10 offline fonts, command palette (Ctrl+K).
- **About** with developer contact cards (Instagram, Telegram, Discord) and **Update Logs** with a version menu.

### Data - complete in all three formats
- JSON, Markdown and text exports now contain **every record** and import back completely. Reports end with a machine-readable data block, so a `.md` or `.txt` file restores exactly like JSON.
- Previously not preserved and now exported and restored: achievement "seen" flags, achievement events, backup details, exact termination reasons and custom categories. Older exports (including `chronos-export` files) still import.
- Verified by an automated field-by-field round-trip test of all three formats (export -> import into a fresh database -> export -> compare).

### Fixed
- Window corners were square.
- Collapsed sidebar text overlapped the icons; it now shows icons only and slides smoothly.
- Timeline took about 10 seconds to open on busy days.
- Statistics, Applications, Sessions and Timeline only refreshed after switching menus.
- Heat Map cells in the Hourly and Weekly views did nothing when clicked.
- Settings sections overlapped when zoomed; themes now sit side by side.
- WatchTower always opened in the tray after launch.
- The installer was ~500 MB because build outputs were packaged inside it (now about 140 MB).

### 3D models
The `watchtower-sky-observer.glb` attached to this release is the Sky Observer tower as a binary glTF 2.0 model (tower and searchlight). The other four models can be exported with `node scripts/export-models.mjs`.
