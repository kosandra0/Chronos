A major expansion. Your data, settings, themes and preferences are kept; every new database structure is additive.

## New
- **Focus mode** - focus/short-break/long-break timer, optional automatic transitions, gentle eye-rest and stretch reminders, pause/resume/skip/stop. Time while the computer sleeps or WatchTower is closed does not count.
- **Application limits** - daily limits for an application or a category, a warning at your threshold (default 80%) and a notice when reached, once per day. Warnings only: nothing is blocked or closed.
- **Weekly screen-time report** - last completed Monday-Sunday week, comparison with the week before, top applications and categories, daily distribution. Delivered once per week as a desktop notification (day and time configurable).
- **Productivity** - classify applications as productive, neutral or distracting (defaults from the category, overrides kept). Score = Productive / (Productive + Distracting) x 100; shown as unavailable when nothing is classified. Daily productive-time goal.
- **Compare periods** - this week vs last week and this month vs last month, in Statistics (Compare tab) and Reports.
- **Projects and client time reports** - projects with client, colour, billable flag and hourly rate; assign sessions from Session details; project totals by period; CSV export; currency setting. These are time reports, not legally valid invoices.
- **Automatic theme schedule** - daytime and night-time themes with start times (also across midnight).
- **Theme packs** - multiple named gradient presets; preview, edit, delete, export selected or all, import with validation (no scripts or CSS are ever executed; existing presets are never overwritten).
- **Updates** - Check for updates in Settings > About, automatic checks (can be turned off), release notes, download with progress, SHA-256 verification against the release's SHA256SUMS.txt, install only after you confirm.
- **Code-signing support** - set `CSC_LINK` and `CSC_KEY_PASSWORD` (or `CSC_NAME`) when building and electron-builder signs the app and installers. `npm run sign:status` reports the configuration; `node scripts/signing-status.cjs --check <files>` verifies signatures.

## Improved
- Applications has the same period selector as Statistics; usage, percentage, sessions, last used and first observed follow the selected period.
- Export/import carries projects and assignments, limits, productivity choices and theme presets (older exports still import).
- Sliding-digit numbers on Focus, Limits, Productivity, Projects, Reports and Compare.
- Settings sections transition smoothly (fade/glide with a sliding highlight) instead of switching instantly.
- Redesigned Level/XP card (Overview and Achievements share one glass design with a crest, gradient progress and a soft hover glow; follows every theme).

## Testing
See the development record; automated suites cover the logic of every feature, the packaged server APIs and the packaged application.

## Limitations
- Builds are **unsigned** unless a trusted certificate is supplied; SmartScreen may warn. Signing does not guarantee instant SmartScreen reputation.
- The portable build cannot replace itself; it opens the release page.
- Email delivery of the weekly report is not implemented (no secure provider is configured).
