A security and stability update to 2.0.0. Your data and settings are untouched.

## Fixed
- **Security:** Next.js updated from 16.4.2 to **16.4.6**, fixing the published advisories about information disclosure and cache leaks in `use cache` / `unstable_cache` (affected 16.0.0 to 16.4.4).
- **Page loads:** removed React hydration errors (#418/#519) on full page loads. The title bar and the updater panel read the desktop bridge while rendering, so the first render differed from the server HTML and React rebuilt the page every time.

## Also in this release
- Everything in [2.0.0](https://github.com/kosandra0/WatchTower/releases/tag/v2.0.0): focus mode, limits, weekly report, productivity, compare periods, projects and client time reports, theme schedule and packs, update checks, redesigned level card.
- The test suite now runs file by file (more reliable) and includes a check that full page loads produce no hydration errors.

## Downloads
- `WatchTower-Setup-2.0.1.exe` - per-user installer (supports in-app update checks; it will offer this update to 2.0.0 installs).
- `WatchTower-Portable-2.0.1-x64.exe` - single-file portable build.
- `SHA256SUMS.txt` - SHA-256 of both files; the in-app updater verifies the installer against it.

Both files are **unsigned**, so Windows SmartScreen may warn on first launch. The animated logo above is rendered from the app's real 3D scene (a looping recording, since GitHub pages cannot run WebGL).
